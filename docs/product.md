# Product

Vela is organized around trust questions.

- Home: what needs trust attention right now?
- Repositories: which repos are healthy, risky or waiting on action?
- Repo overview: can I trust the current state of this repo?
- PR cockpit: can I trust this change?
- Launch cockpit: can this release candidate ship?
- Agents: which machine actors are active, trusted, risky or blocked?
- Evidence ledger: can we reconstruct what happened?
- Settings: what controls trust and access?

The PR cockpit is the core product surface. Its order is fixed: decision banner, readiness score, behavioral summary, risk map, test evidence, agent provenance, review requirements, merge simulation, rollback plan, raw diff and comments.
