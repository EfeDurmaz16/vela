# Roadmap

## Phase 0: Foundation

Phoenix app, Postgres schema, seeded demo workspace, app shell, repo overview, PR cockpit, agents, launches, evidence ledger, settings, docs, scripts and tests.

## Phase 1: Beautiful Private Forge

WorkOS auth, repository CRUD, branch protection, issues, comments, reviews, GitHub import/mirror models, metadata search and repository settings.

## Phase 2: Best PR Experience

Semantic summaries, changed behavior, risk maps, test evidence, merge simulation detail, rollback plans, agent provenance and real diff integration.

## Phase 3: Vela Maestro

Python analysis service, adapters for tests/security/performance/UX/API analysis, score explanations, callbacks and evidence-backed analysis runs.

## Phase 4: Agent-Native Forge

Agent registration, tokens, public keys, signatures, branch leases, policy UI, tool timelines, human supervision and conflict detection.

## Phase 5: Enterprise Trust

SSO, SCIM, advanced RBAC, audit exports, self-hosted docs, data residency, compliance reports, private model gateway and hardened runner isolation.
