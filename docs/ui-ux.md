# UI and UX

Vela should feel premium, calm and deeply useful.

The UI is monochrome-first with restrained status color. It should feel like a serious infrastructure workbench, not a generic SaaS dashboard. Avoid robot gimmicks, fake cyberpunk, excessive gradients, noisy borders and nested card clutter.

Each page answers one primary trust question. Raw complexity is progressively disclosed. The PR cockpit leads with decision, evidence and risk before raw diff.

Phase 0 uses LiveView components. React islands are deferred until a component needs high-interaction behavior such as a diff viewer, graph, code browser or policy builder.
